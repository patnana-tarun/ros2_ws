## Verified
- Tunnel-reverse, 3 GUI runs: reversing in open space 0–0.7 % (reverse-out 25–36 %), in tunnels
  11–14 %, 0 spins, start-up U-turn about 200°. Open-area heading p90 18–23° (reverse-out 6–13°
  in 3 of 4 runs). None reached 90 %: all 3 ended wedged in passages 0.55–0.85 m wide.
- The wedge: the explorer sent goals back out and the planner found valid paths, but the reverse
  controller commanded |vx| < 0.03 m/s for over a minute. That controller is identical to
  reverse-out's, and reverse-out run 1 ended the same way (B-E tunnel).
- Reverse-out confirmation: 4 runs, 0 spins in all, start-up turning 3–14°, goal success 53–79 %,
  90 % reached in 9.6–13.8 min (3 of 4). Run 4's open-area flag is arcing into right-angle paths
  (cross-track ≤ 9 cm), not drift.
- Reverse-out (user's idea), track 0.38, 2 GUI runs ([[Reverse-out 2026-10-20]]): 0 spins, 8°
  start-up turning, 0.55 % large open-area deviations, 12 % stuck, 65 % goal success. Path held
  while reversing (cross-track p90 3 cm). The three-point-turn variant only reversed (MPPI can't
  plan the forward leg).
- Gentler turning in the nav config (track 0.43; turn acceleration 1.0 or 0.5 rad/s²): spins go
  from 0 (kept version) to 46–49 per run, and large open-area deviations to 24–26 %. Rejected.
  The kept version reproduces on a second day.
- "Before" rerun (3 GUI runs): 17 % stuck (22/9/19), indistinguishable from all planner fixes at
  track 0.43 (p = 1.00). The planner fixes cost no stuck time; the extra comes from the 0.34 track.
- The 0.34 m sim track width is what removes the spins (0 vs 3.3 per run at 0.43), shortens
  the start-up turn (about 40° vs 142°) and halves the open-area deviations. It is also what
  caps MPPI's turn commands at about 0.2 rad/s.
- All 15 runs with the demo fixes stalled more than the 3 "before" runs (14–49 % vs 3–12 %,
  p = 0.002). No single undone change brings it back. The pre-check helps (undone: 43 %).
- `skid_track:=0.43` reaches the sim (`wheel_separation` 0.43 in `robot_description`). The cave
  world is unchanged (same checksum as committed). RTF 1.000 in all runs.
